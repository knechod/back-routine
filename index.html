Back Maintenance Routine

⏱ 20–30 min · 3×/week (after transition) 🧘 Warm-up daily 🎯 Prevent flare-ups
B.02.06 — Transition + Strength Plan · Updated 2026-05-24
Time Expectation Full routine (Week 3/4): ~30–38 minutes. If you keep all optional 2nd sets, plan closer to the high end.
Rule Pain-free only  ·  Light weights  ·  Slow control  ·  Stop if sharp pain occurs
Every Day · 0–3 Minutes
Warm-Up learn more ↗
Do this every morning, even on rest days
  • Standing pelvic tilts – 10 slow reps
  • Shoulder rolls (backward) – 5 reps
  • Gentle torso turns – 5 reps each side
Week 1 — Transition (Add 2 moves)
Mon · Thu · Sat Keep your current routine + add two moves · ~5–10 min extra
Estimated total: ~18–24 minutes
Transition rulesNew moves: 1 set only · Keep weights exactly as listed · Stop if sharp pain
Cable Supported Squat New learn more ↗
4–6 min
FTX Setup: Two D-handles · Pulleys at mid-chest height · Start: 5 lb per side
  • 8 reps (slow and smooth)
  • Optional 2nd set only if pain-free and easy
Cue: Sit back as if to a chair · Ribs stacked over hips · No pain
Cable Chest Press (Split Stance) New learn more ↗
4–6 min
FTX Setup: One D-handle · Pulley at chest height · One pulley / one stack · Start: 10 lb
  • 8 reps each side (smooth, no snapping lockout)
  • Optional 2nd set
Cue: One foot forward for balance · Exhale on press · Keep ribs down
Straight-Arm Pulldown learn more ↗
4–6 min
FTX Setup: Rope · Pulley above head · One pulley / one stack · Start: 10 lbStart: 5 lb per side
  • 10–12 reps
  • Optional 2nd set
Cue: Pull to thighs, abs lightly braced
Pallof Press learn more ↗
3–4 min
FTX Setup: Pulley at chest height · Single D-handle · Start: 5 lb
  • 8 reps – Left side
  • 8 reps – Right side
  • Optional 2nd set
Cue: Brace lightly and resist rotation
Face Pull (Posture / Shoulders) New learn more ↗
3–4 min
FTX Setup: Rope · Pulley at face height · One pulley / one stack · Start: 10 lb
  • 10 reps (pause 1 second at the pull)
  • Optional 2nd set
Cue: Elbows up/out · Shoulder blades back/down · Neck relaxed
Seated Cable Row (Rope · Single Pulley) New learn more ↗
4–6 min
FTX Setup: Rope · Pulley at mid-torso height · One pulley / one stack · Start: 10 lb
  • 10 reps (alternate sides, 5 each)
  • Optional 2nd set
Cue: Sit tall · Pull elbow to hip · No torso twist

Quick Safety Check — After Every Session
  • No sharp pain during session
  • No increase in pain afterward
  • Back feels same or better next morning
